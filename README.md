# One Word, One Username, One Reward

Our own make.fun username, one word and nothing else, written for the [Make.fun bounty](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae).

`main.py` writes the username to `/output/entry.txt`:

Run it with `python3 main.py`.
